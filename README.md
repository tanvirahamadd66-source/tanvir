# Tanvir Creates — Portfolio Website

A static, dependency-free HTML/CSS/JS portfolio site. No build step, no frameworks —
open `index.html` in a browser and it works, or deploy the folder as-is to any static host.

## Previewing locally

Just double-click `index.html`, or from this folder run a tiny local server (recommended,
some browsers restrict local file access for fetch/relative paths):

```
# Python
python -m http.server 8000

# Node
npx serve .
```

Then open `http://localhost:8000`.

## Adding more Behance projects later

1. Publish the project on Behance.
2. Add an entry to `js/behance-projects-data.js` (title, category, description, tags, image URLs).
3. Download its images into `assets/img/projects/behance/<slug>/`.
4. Run `node scripts/generate-project-pages.js` to regenerate the detail page.

## Making the contact form send email

A static site has no server, so the form can't send email on its own yet. Two options:

1. **Formspree / Web3Forms (recommended, free tier available)** — sign up, create a form,
   copy the endpoint URL, and paste it into `CONFIG.formEndpoint` in `js/main.js`. No other
   code changes needed.
2. **Do nothing** — the form already falls back to opening the visitor's default email app
   with the message pre-filled, addressed to `CONFIG.contactEmail`. Works everywhere, no
   signup required, slightly less smooth UX.

## Customizing content

- **Text content** (bio, services, process, etc.) — edit directly in `index.html`, it's plain
  semantic HTML with clear section comments (`<!-- ============ ABOUT ============ -->` etc.).
- **Projects** — edit `js/projects-data.js`. Adding an image/description/link to a featured
  project automatically upgrades its card — no HTML/CSS editing required.
- **Colors** — the whole palette is CSS custom properties at the top of `css/style.css`
  (`:root` for light mode, `:root[data-theme="dark"]` for dark mode). Change values there to
  restyle the entire site at once.
- **Fonts** — currently Space Grotesk (headings) + Inter (body), loaded from Google Fonts in
  `index.html`. Swap the `<link>` and the `--font-display`/`--font-body` variables in
  `style.css` to change.

## Deployment options

Any static host works since there's no server/build step:

- **Netlify** — drag and drop this folder onto app.netlify.com/drop, or connect a Git repo.
- **Vercel** — `vercel deploy` from this folder, or connect via the dashboard.
- **GitHub Pages** — push this folder to a repo and enable Pages on the `main` branch.

Once you buy your domain, point its DNS to whichever host you pick (each has simple docs
for connecting a custom domain).
